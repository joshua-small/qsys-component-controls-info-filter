# Component Controls Info Filter 0.1.2

Floating Component Controls Info windows keep their descriptive title, normal single-border style and taskbar visibility after docking, refloating or reopening. The main Designer window is excluded. The active filter and query are retained when the inspector moves between hosts.

Adds Windows regression coverage for the floating-window properties, main-window exclusion and retained-inspector lifecycle alongside the portable filtering suite.

Validated on Designer 10.5.0 with Mods Core 0.1.11: two dock/float cycles, floating close/reopen, reopening an existing inspector docked and then floating it, Ctrl+F, filtering, copying and Clear. Main-window properties and design/history state were preserved. The standalone Windows suite passed 18/18 cases; the portable suite passed 40/40.

A brand-new inspector first constructed docked has standalone test coverage only. Two-component query switching, direct underlying source-text readback, theme coverage, shell taskbar-button interaction and Designer 10.5.1 remain outside this recorded acceptance.

Requires Q-SYS Mod Manager 0.8+ and Mods Core 0.1.x. Schematic Tools versions before 0.17.0 must be migrated through the manager.
