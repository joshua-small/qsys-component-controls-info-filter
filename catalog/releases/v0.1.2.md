# Component Controls Info Filter 0.1.2

Floating Component Controls Info windows keep their descriptive title, normal single-border style and taskbar visibility after docking, refloating or reopening. The main Designer window is excluded. The active filter and query are retained when the inspector moves between hosts.

Adds Windows regression coverage for the floating-window properties, main-window exclusion and retained-inspector lifecycle alongside the portable filtering suite.

Validated on Designer 10.5.0 with Mods Core 0.1.11: two dock/float cycles, floating close/reopen, reopening an existing inspector docked and then floating it, Ctrl+F, filtering, copying and Clear. Active queries followed two real components without stale rows, while direct readback confirmed that the complete native source lists remained intact. Light and dark styles retained readable query, count and output after refloating, with working focus and input.

The same DLL passed focused checks on Designer 10.5.1 with Mods Core 0.1.11: physical filter input, switching between two components with an active query, one dock/float cycle, Ctrl+F and typing after refloat, light/dark readability, floating close/reopen and Clear. The complete source lists and same inspector were retained without model, dirty-state or history changes. Native preferences and mod settings were restored after normal exit. The broader 10.5.0 checks remain separately attributed.

The standalone Windows suite passed 18/18 cases; the portable suite passed 40/40. A brand-new inspector first constructed docked has standalone coverage only. Actual shell taskbar-button interaction remains unvalidated. No connected-Core, hardware or broad build compatibility support is claimed.

The package retains its original 10.5.0 compatibility declaration. On 10.5.1, Q-SYS Mod Manager 0.12 uses its explicit untested-build consent flow. Requires Mods Core 0.1.x; Manager 0.8+ handles the package on its declared build. Schematic Tools versions before 0.17.0 must be migrated through the manager.
